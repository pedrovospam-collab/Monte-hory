# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Repozitář obsahuje kompletní Montessori lekci "Hory" pro děti 4–6 let — jde o obsahový/kurikulární projekt v Markdown, nikoli softwarovou aplikaci. Neexistuje žádný build, test ani lint proces.

## Structure

- `program-hory-montessori.md` — hlavní přehled lekce (master dokument)
- `podklady/` — podrobné materiály (scénář, specifikace karet, infografik, checklist)
  - Soubory `01`–`10` jsou řazeny logicky; pořadí čtení viz `podklady/README.md`

## Key Documents

- `podklady/01-scenar-pruvodce.md` — scénář průvodce (co říkat a dělat v každém bloku)
- `podklady/09-tri-bodove-lekce.md` — skripty tříbodových lekcí (Montessori metodika)
- `podklady/10-checklist-materialu.md` — checklist materiálů, timeline přípravy, rozpočet (~2050 Kč)
- `podklady/08-infografiky.md` — specifikace 5 plakátů A2

## Content Principles

- **Realita, ne fantazie** — žádný yeti, žádná dramatizace, pouze fakta
- **Smyslové zážitky** — hmatové poznávání materiálů před abstrakcí
- **Minimální jazyk** — průvodce mluví málo, pomalu, s pauzami
- **Realistické fotografie** — žádné kreslené ilustrace
- **Bez nátlaku** — žádné odměny, soutěže, nucená účast
- **Bez závěrečného rituálu** — žádné společné foto, suvenýry, zpětná vazba

## Formatting Conventions

- Všechny dokumenty jsou v češtině, formát Markdown
- Specifikace karet: formát A6 (105 × 148 mm), bezpatkové písmo (Quicksand, Nunito, Verdana)
- Plakáty: formát A2, laminované, max 5 slov na plakát
